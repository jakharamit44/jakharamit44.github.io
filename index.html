Brainzap YouTube Uploader

Brainzap YouTube Uploader is a personal automation tool built for the Brainzap Daily YouTube channel (youtube.com/@brainzaphindi), a Hindi science-facts channel.

What it does:

  • Uploads short Hindi science-facts videos (Shorts) to the Brainzap Daily channel using the YouTube Data API.
  • Adds each uploaded Short to the channel's public "Brainzap Daily Shorts" playlist.
  • Runs only for the channel owner. It is not offered to other users and it does not collect data from anyone else.

How it works: the channel owner signs in once with Google, grants the tool permission to manage their own YouTube videos, and the tool uses that permission to publish the owner's own videos. Nothing is posted anywhere except the owner's own channel.

Read how Google user data is handled in the Privacy Policy.
